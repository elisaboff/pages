React — fundamentos

React é uma biblioteca JavaScript para construir interfaces com componentes — blocos independentes e reutilizáveis de UI.

Conceito 1

O que é um componente?

Um componente é uma função JavaScript que retorna JSX (HTML dentro do JavaScript). Pense nele como uma peça de Lego da sua interface.

// Definindo um componente
function Cartao({ titulo, cor }) {
  return (
    <div style={{ background: cor, padding: '1rem', borderRadius: 8 }}>
      <h2>{titulo}</h2>
      <p>Conteúdo do cartão</p>
    </div>
  );
}

// Usando o componente no App
function App() {
  return (
    <div>
      <Cartao titulo="Olá!" cor="coral" />
      <Cartao titulo="Mundo" cor="skyblue" />
    </div>
  );
}
As chaves {} dentro do JSX executam JavaScript. {titulo} exibe o valor da variável. As propriedades passadas ao componente se chamam props.
Conceito 2

Estado com useState

Estado (state) é um dado que, quando muda, atualiza automaticamente a interface. É o coração das interações no React.

import { useState } from 'react';

function Contador() {
  // [valor atual, função para alterar o valor]
  const [numero, setNumero] = useState(0);

  return (
    <div>
      <p>Você clicou {numero} vezes</p>

      <button onClick={() => setNumero(numero + 1)}>
        Aumentar
      </button>

      <button onClick={() => setNumero(0)}>
        Zerar
      </button>
    </div>
  );
}
Nunca altere o estado diretamente como numero = 5. Sempre use a função setNumero(5) — só assim o React sabe que precisa atualizar a tela.
Conceito 3

Referências com useRef

O useRef cria uma referência direta a um elemento do DOM — essencial para integrar GSAP e p5.js, que precisam do elemento real para funcionar.

import { useRef } from 'react';

function MeuComponente() {
  const divRef = useRef(null); // começa como null

  const destacar = () => {
    // divRef.current é o elemento <div> real no DOM
    divRef.current.style.background = 'coral';
  };

  return (
    <div>
      <div ref={divRef} style={{ padding: 20 }}>
        Clique para me colorir!
      </div>
      <button onClick={destacar}>Colorir</button>
    </div>
  );
}
Conceito 4

Efeitos com useEffect

O useEffect executa código depois que o componente aparecer na tela. É aqui que você inicia animações GSAP e sketches p5.js.

import { useEffect, useRef } from 'react';

function Exemplo() {
  const ref = useRef(null);

  useEffect(() => {
    // Roda quando o componente aparece na tela
    console.log('Elemento disponível:', ref.current);

    // A função de retorno roda quando o componente sai
    return () => {
      console.log('Limpando...');
    };
  }, []); // [] = executa apenas uma vez

  return <div ref={ref}>Olá!</div>;
}
O [] no segundo argumento do useEffect é importante: sem ele, o código roda a cada renderização. Com [], roda só uma vez ao aparecer.
Exemplo completo

Renderização de lista com estado

import { useState } from 'react';

const itensIniciais = ['Maçã', 'Banana', 'Laranja'];

function ListaDeFrutas() {
  const [frutas, setFrutas] = useState(itensIniciais);
  const [nova, setNova] = useState('');

  const adicionar = () => {
    if (nova.trim() === '') return;
    setFrutas([...frutas, nova]); // cria novo array com o item
    setNova(''); // limpa o campo
  };

  return (
    <div>
      <ul>
        {frutas.map((f, i) => (
          <li key={i}>{f}</li>
        ))}
      </ul>

      <input
        value={nova}
        onChange={e => setNova(e.target.value)}
        placeholder="Nova fruta..."
      />
      <button onClick={adicionar}>Adicionar</button>
    </div>
  );
}

GSAP — animações profissionais

GSAP (GreenSock Animation Platform) é o motor de animação mais usado na web. Anima qualquer propriedade CSS, SVG ou objeto JavaScript com controle total.

Setup

Como incluir o GSAP

Em HTML puro — adicione no <head> ou antes do fechamento do <body>:

<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>

Em projeto React — instale via npm e importe:

npm install gsap

import { gsap } from 'gsap';
Método 1

gsap.to() — animar até um estado

O método mais usado. Anima um elemento até os valores que você definir, partindo do estado atual.

// Seleciona por classe CSS e anima
gsap.to(".caixa", {
  x: 300,           // move 300px para a direita
  y: -50,           // sobe 50px
  rotation: 360,    // gira 360 graus
  scale: 1.5,       // aumenta 50%
  opacity: 0.5,     // fica semitransparente
  duration: 2,      // em 2 segundos
  ease: "bounce.out" // com efeito quique no final
});

// Também funciona com múltiplos elementos
gsap.to(".item", {
  x: 100,
  stagger: 0.2,     // cada elemento espera 0.2s a mais
  duration: 0.8
});
Método 2

gsap.from() e gsap.fromTo()

from() define de onde a animação começa (o elemento já está no destino final). fromTo() define início E fim explicitamente.

// O elemento já está no lugar — gsap.from define o ponto de partida
gsap.from(".titulo", {
  y: -60,       // vem de 60px acima
  opacity: 0,   // começa invisível
  duration: 1,
  ease: "power2.out"
});

// Define início e destino explicitamente
gsap.fromTo(".caixa",
  { opacity: 0, scale: 0.3, rotation: -45 },   // DE aqui...
  { opacity: 1, scale: 1,   rotation: 0, duration: 1 } // ATÉ aqui
);
Timeline

Sequências com gsap.timeline()

A timeline encadeia animações em ordem e com controle preciso de tempo. Essencial para animações de entrada complexas.

// Cria a sequência
const tl = gsap.timeline({ defaults: { duration: 0.5 } });

tl.from(".fundo",    { opacity: 0 })
  .from(".titulo",   { y: -40, opacity: 0 })
  .from(".subtitulo",{ y: -20, opacity: 0 }, "-=0.2") // começa 0.2s antes do fim anterior
  .from(".botao",    { scale: 0, ease: "back.out(2)" })
  .to(".decoracao",  { rotation: 360, duration: 1 }, "<"); // "<" = junto com o anterior

// Você pode pausar, reiniciar e controlar a timeline
tl.pause();
tl.play();
tl.restart();
tl.reverse();
O símbolo "<" significa "ao mesmo tempo que o anterior" e "-=0.2" significa "0.2 segundos antes do anterior terminar". São os controles de tempo mais usados.

No React

GSAP dentro de um componente React

import { useEffect, useRef } from 'react';
import { gsap } from 'gsap';

function BlocoAnimado() {
  const elementoRef = useRef(null);

  useEffect(() => {
    // Anima quando o componente aparecer
    gsap.from(elementoRef.current, {
      y: 80,
      opacity: 0,
      duration: 0.9,
      ease: "power3.out"
    });
  }, []);

  return (
    <div
      ref={elementoRef}
      style={{ background: 'coral', padding: '2rem', borderRadius: 12 }}
    >
      <h2>Eu apareço animado!</h2>
    </div>
  );
}

p5.js — arte e programação criativa

p5.js é uma biblioteca JavaScript inspirada no Processing, pensada para artistas e designers. Ela facilita a criação de gráficos, animações e experiências interativas no canvas do navegador.

Estrutura base

As duas funções essenciais

Todo sketch de p5.js é construído em volta de duas funções:

function setup() {
  // Roda UMA VEZ quando o sketch inicia
  createCanvas(600, 400); // cria uma tela de 600x400 pixels
  background(220);        // preenche o fundo (0=preto, 255=branco)
}

function draw() {
  // Roda em LOOP contínuo (~60 vezes por segundo)
  // Aqui ficam as animações e interações

  ellipse(mouseX, mouseY, 50, 50); // desenha onde o mouse estiver
}
mouseX e mouseY são variáveis automáticas do p5.js — você não precisa declarar nada para ter acesso à posição do mouse!
Formas e cores

Desenhando formas básicas

function setup() {
  createCanvas(500, 350);
}

function draw() {
  background(30);          // fundo quase preto

  // Cor de preenchimento: fill(R, G, B) ou fill(cinza)
  fill(255, 100, 50);      // laranja
  stroke(255, 255, 0);     // contorno amarelo
  strokeWeight(3);         // espessura do contorno

  rect(50, 50, 150, 100);  // retângulo(x, y, largura, altura)
  ellipse(300, 120, 100);  // círculo(x, y, diâmetro)

  fill(100, 200, 255);
  noStroke();              // sem contorno
  triangle(400,50, 370,150, 430,150);

  stroke(255);
  line(50, 200, 450, 300); // linha(x1, y1, x2, y2)
}
Animação

Criando movimento com variáveis

let x = 0;
let velocidade = 4;

function setup() {
  createCanvas(500, 200);
}

function draw() {
  background(20); // redesenha o fundo a cada frame (apaga rastro)

  // Desenha a bolinha na posição x
  fill(80, 200, 255);
  noStroke();
  ellipse(x, height / 2, 50);

  x = x + velocidade; // avança para a direita

  // Quando sair da tela, volta ao início
  if (x > width + 25) {
    x = -25;
  }
}
width e height são variáveis automáticas que guardam o tamanho do canvas. Use sempre em vez de números fixos!
Interatividade

Respondendo ao mouse e teclado

function setup() {
  createCanvas(500, 300);
  background(20);
}

function draw() {
  // map() converte um valor de um range para outro
  // Aqui: posição X do mouse (0 a 500) vira cor (0 a 255)
  let r = map(mouseX, 0, width, 0, 255);
  let b = map(mouseY, 0, height, 255, 0);

  // 4º parâmetro do fill = transparência (0-255)
  fill(r, 80, b, 120);
  noStroke();

  // Só desenha se o mouse estiver pressionado
  if (mouseIsPressed) {
    ellipse(mouseX, mouseY, 40);
  }
}

// Funções que respondem a eventos específicos:
function mousePressed() {
  // Roda uma vez quando o botão do mouse é pressionado
  console.log('Clicou em:', mouseX, mouseY);
}

function keyPressed() {
  if (key === 'c' || key === 'C') {
    background(20); // limpa a tela pressionando 'C'
  }
}

No React

p5.js dentro do React

Use o pacote react-p5 para integrar facilmente:

npm install react-p5

import Sketch from 'react-p5';

function MeuSketch() {
  const setup = (p5, canvasParentRef) => {
    p5.createCanvas(500, 300).parent(canvasParentRef);
    p5.background(20);
  };

  const draw = (p5) => {
    let r = p5.map(p5.mouseX, 0, p5.width, 0, 255);
    p5.fill(r, 100, 200, 150);
    p5.noStroke();
    p5.ellipse(p5.mouseX, p5.mouseY, 40);
  };

  const mousePressed = (p5) => {
    p5.background(20); // limpa ao clicar
  };

  return <Sketch setup={setup} draw={draw} mousePressed={mousePressed} />;
}
Com o react-p5, todas as funções do p5.js passam a ser métodos do objeto p5 (primeiro parâmetro). Então ellipse() vira p5.ellipse().

Combinando React + GSAP + p5.js

As três ferramentas se complementam perfeitamente. Veja como organizar um projeto que usa as três:

p5.js

Exemplo

Projeto: fundo generativo com menu animado

O p5.js cria partículas no fundo. O React organiza os componentes. O GSAP anima a entrada do menu.

// App.jsx
import { useEffect } from 'react';
import { gsap } from 'gsap';
import Sketch from 'react-p5';

function App() {
  // GSAP: anima o menu ao entrar
  useEffect(() => {
    gsap.from(".menu-item", {
      y: -30,
      opacity: 0,
      stagger: 0.15,
      duration: 0.7,
      ease: "power2.out",
      delay: 0.3
    });
  }, []);

  // p5.js: fundo com partículas
  const setup = (p5, ref) => {
    p5.createCanvas(p5.windowWidth, p5.windowHeight).parent(ref);
  };

  const draw = (p5) => {
    p5.background(10, 10, 20, 25); // fundo com rastro (alpha baixo)
    p5.fill(100, 180, 255, 180);
    p5.noStroke();
    // Partícula que orbita usando seno/cosseno
    let x = p5.width/2  + p5.cos(p5.frameCount * 0.01) * 200;
    let y = p5.height/2 + p5.sin(p5.frameCount * 0.02) * 100;
    p5.ellipse(x, y, 8);
  };

  return (
    <div style={{ position: 'relative', height: '100vh' }}>

      {/* Fundo: canvas p5.js */}
      <div style={{ position: 'absolute', inset: 0, zIndex: 0 }}>
        <Sketch setup={setup} draw={draw} />
      </div>

      {/* Conteúdo: menu animado por GSAP */}
      <nav style={{ position: 'relative', zIndex: 1, padding: '2rem' }}>
        {['Início', 'Sobre', 'Projetos', 'Contato'].map(item => (
          <a key={item} className="menu-item" href="#"
            style={{ display: 'block', color: 'white', marginBottom: 12 }}>
            {item}
          </a>
        ))}
      </nav>

    </div>
  );
}

export default App;

Ideias de projeto criativo

Projetos que combinam as três ferramentas de forma interessante para uma hipermídia criativa:

Ideia 1

Portfólio com fundo vivo

Um portfólio pessoal onde o fundo é um sketch p5.js (partículas, ondas, constelações). Cada seção entra com animação GSAP. O React organiza as seções e o conteúdo.

Desafio criativo: o fundo responde ao scroll — cada seção ativa muda as cores e forma das partículas.

Ideia 2

Livro/história interativa

Um conto dividido em capítulos. Cada virada de página é animada com GSAP. O cenário de cada capítulo é desenhado em p5.js (chuva, estrelas, ondas do mar). O React gerencia o estado da narrativa.

Desafio criativo: decisões do leitor mudam o caminho da história (state do React) e os visuais do p5.js.

Ideia 3

Visualizador de dados artístico

Dados reais (clima, redes sociais, música) visualizados de forma artística com p5.js. Filtros e seleções feitos em React. Transições entre visualizações animadas com GSAP.

Desafio criativo: a visualização muda em tempo real enquanto o usuário arrasta sliders.

Ideia 4

Jogo narrativo / experiência imersiva

Cenários interativos desenhados em p5.js com física básica (gravidade, colisões). Cutscenes e transições animadas com GSAP Timeline. O React gerencia o inventário, diálogos e progressão.

Ideia 5

Gerador de arte interativo

O usuário controla parâmetros (cor, velocidade, forma) via sliders e botões feitos em React. O p5.js gera arte generativa em tempo real baseada nesses parâmetros. O GSAP anima os controles e feedbacks visuais da interface.
