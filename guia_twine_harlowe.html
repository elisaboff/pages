🗺️ Mapa da história — "A Floresta das Escolhas"
💡 A história tem 7 passagens e 3 níveis hierárquicos, atendendo aos requisitos mínimos da tarefa. Repare que a clareira é acessível por todos os caminhos — é o nó de convergência antes do fim.
⌨️ Sintaxe principal — Harlowe
Links entre passagens
[[Texto do link->nome-da-passagem]]

-- Exemplos --
[[Entrar na floresta->inicio]]
[[Sair daqui->https://twinery.org]]

-- Sintaxe alternativa (nome=texto) --
[[nome-da-passagem|Texto do link]]

O texto antes da seta → aparece para o leitor. O nome após a seta é o nome interno da passagem no Twine.

Variáveis — definir e atualizar
-- Criar / definir --
(set: $nome to "Viajante")
(set: $coragem to 0)
(set: $vivo to true)

-- Atualizar --
(set: $coragem to $coragem + 1)
(set: $coragem to $coragem - 1)

Variáveis começam com $. Use (set:) tanto para criar quanto para alterar. Tipos: texto, número, booleano (true/false).

Exibir variáveis na tela
-- Exibir valor --
Olá, (print: $nome)!
Coragem: (print: $coragem)

-- Atalho: apenas $variavel --
Olá, $nome! Coragem: $coragem

-- Exibir no título da janela --
(display: "nome-da-passagem")

Em Harlowe, você pode usar $variavel diretamente no texto — o Twine substitui pelo valor automaticamente.

Condições — if / else-if / else
(if: $coragem >= 2)[
  Você é corajoso!
  [[Avançar->saida_heroi]]
](else-if: $coragem is 1)[
  Você hesita, mas tenta.
  [[Tentar->saida_fraco]]
](else:)[
  Você recua com medo.
  [[Voltar->inicio]]
]

O conteúdo entre [ ] só aparece quando a condição é verdadeira. Operadores: is, >=, <=, >, <, is not.

Listas (arrays)
-- Criar lista vazia --
(set: $itens to (a:))

-- Adicionar item --
(set: $itens to $itens + (a: "mapa"))

-- Verificar se item existe --
(if: "mapa" is in $itens)[
  Você tem o mapa!
]

Listas permitem criar inventários. Use (a:) para criar uma lista, + para adicionar itens, e is in para verificar.

Mídia e estilos
-- Imagem --
<img src="url-da-imagem.jpg" width="100%">

-- Estilo inline --
(text-colour: "red")[Texto vermelho]
(text-style: "bold")[Negrito]
(background: "#1a1a2e")[Fundo]

-- CSS global (Story Stylesheet) --
tw-story { background: #1a1a2e; }
tw-passage { color: #e8dcc8; }

HTML funciona normalmente dentro do Twine. Para estilos globais, use o Story Stylesheet (menu da história).

is== (igual)(if: $coragem is 2)
